Лабораторная работа №7: Многопоточность в Java
Описание

Многопоточность в Java позволяет выполнять несколько задач одновременно в рамках одного приложения. Это значительно увеличивает производительность при обработке больших объемов данных и позволяет эффективно распределять ресурсы процессора.

Ключевые инструменты и методы

Thread / Runnable — базовые способы создания и запуска потоков в Java

    synchronized — модификатор для обеспечения исключительного доступа к общему ресурсу
    
    join() — метод, заставляющий главный поток ожидать завершения работы дочернего потока
    
    ExecutorService — высокоуровневый интерфейс для управления пулом потоков и распределения задач
    
    ForkJoinPool — специализированный пул потоков для эффективного решения задач по принципу «разделяй и властвуй»

Содержание заданий
1. Многопоточное вычисление суммы элементов массива
   
    Реализация параллельного сложения чисел с использованием пула потоков ExecutorService
    
    Массив разделяется на равные части, каждая из которых обрабатывается отдельным потоком
    
    Главный поток агрегирует результаты вычислений после завершения работы всех задач

2. Поиск наибольшего элемента в матрице
 
    Параллельный поиск максимального значения в двумерном массиве с помощью пула потоков
    
    Матрица делится на сегменты для независимой обработки рабочими потоками
    
    Финальное сравнение локальных максимумов происходит в главном потоке программы

3. Симуляция работы склада (Вариант 6)

    Многопоточная модель переноса товаров весом до 150 кг группой из 3 грузчиков
    
    Использование ForkJoinPool для декомпозиции общей задачи склада на более мелкие подзадачи
    
    Синхронизация процесса погрузки и разгрузки при достижении лимита веса
