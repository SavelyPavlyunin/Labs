Лабораторная работа №2: Объектно-ориентированное программирование на Java Описание

Данная лабораторная работа посвящена изучению и практическому применению основных концепций объектно-ориентированного программирования (ООП) в языке Java. В ходе работы реализована иерархия классов, демонстрирующая механизмы наследования, инкапсуляции, полиморфизма и абстракции. Основные концепции ООП в проекте

В проекте реализованы следующие принципы:

  Абстракция: Использование абстрактных классов для определения общей структуры сущностей без необходимости создания их экземпляров.

  Инкапсуляция: Использование модификаторов доступа (private), а также методов доступа (геттеров и сеттеров) для защиты данных объекта.

  Наследование: Создание двухуровневой иерархии классов с использованием ключевого слова extends для повторного использования кода.

  Полиморфизм: Переопределение методов родительского класса (@Override) и использование перегрузки конструкторов.
